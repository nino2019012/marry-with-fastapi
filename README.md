# worklog-management-system (출퇴근 기록 공유 시스템)

## 1. 기획 배경 및 비즈니스 전략
* 현장 데이터 공유: 아르바이트 현장의 출퇴근 정보를 상호 간 공유하여 오해와 갈등을 예방한다.
* 유저 부담 최소화: 5인 이상 사업장 여부는 사용자(사장님)가 매장 현황을 확인하는 용도로만 체크한다. 복잡한 수당 계산 강제로 인한 유저 이탈과 부담감을 방지한다.
* 출퇴근 기록 집중: 갈등의 본질인 출퇴근 기록 공유 무결성에 집중한다.

## 2. 기술 스택 및 주요 구현
* Backend: FastAPI (Python), SQLModel, SQLAlchemy
* Frontend: React (TypeScript)
* 목표: 빠른 수정 및 보완을 위해서 RESTful API로 구축한다. 해당 프레임워크와 비즈니스 로직의 결합도를 낮추기 위해서 파일 간 분리에 집중하여 유지보수성 향상을 목표로 한다.
